# Quality Goals – Parking Management System

## 1. Purpose

This document describes the software quality goals relevant to the Parking Management System developed for the BBAT104: Fundamentals of TQM course project.

## 2. Quality Goals

The project guidelines define 20 quality goals, from Q01 to Q20, covering reliability, performance, usability, security, response time, duplicate prevention, data accuracy, user satisfaction, bug reduction, documentation, maintainability, accessibility, search and retrieval, navigation, reporting, testing, memory usage, error handling, continuous improvement, and overall software quality.

## 3. Implementation Status
