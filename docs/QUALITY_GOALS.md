# Quality Goal Selection

The course guidelines require each student to implement any five suggested features from the Quality Goal assigned through the roll-number allotment. This project includes a balanced default feature set: input validation, audit trail, dashboard, fast search/filter, CSV export, user-friendly errors and modular code.

Before final submission:
1. Check your assigned Q01–Q20 in the allotment sheet.
2. Select the five features that match that exact goal.
3. Mark the implemented features and add evidence/screenshots.
4. Do not state that the project satisfies a different assigned goal without mapping the features.
