# Defect Categories for Checksheets

Use consistent categories when recording actual test defects:
- **Validation:** blank, malformed or out-of-range input accepted/rejected incorrectly.
- **Data integrity:** duplicate active vehicle or slot, inconsistent record state.
- **Slot allocation:** wrong slot, occupied slot reused, capacity exceeded.
- **Billing:** incorrect billed duration, hourly rate or total fee.
- **Search and navigation:** incorrect filter results or confusing action flow.
- **Reporting/export:** missing columns, malformed CSV, wrong row count.
- **Reliability:** unhandled exception, database error, lost update.
- **Usability:** unclear messages, missing confirmation or inaccessible control.
