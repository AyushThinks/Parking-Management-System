# Project Scope and Constraints

## In scope
- Local parking operations for a single facility
- Vehicle registration, slot allocation, exit, billing and history
- Search, CSV export, settings and audit trail
- Quality engineering documentation and test evidence

## Out of scope
- Online payments and refunds
- ANPR/camera integration
- RFID/card access, physical barrier control or sensor integration
- Multi-user concurrent cloud deployment
- Production security certification

## Constraints
Python/Tkinter desktop UI and SQLite local storage are used to align with the course guideline. The fee model is illustrative and should be confirmed with the evaluator if a different rule is expected.
